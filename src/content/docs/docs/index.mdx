**Screensemble — An ensemble of screens.** Signage That Takes the Stage.

Screensemble is a self-hosted digital signage system built for art galleries,
studios, and small venues. Every display always shows an intentional state —
never a blank screen, a media-player home screen, or an OS launcher.

## What's here

- **[Get started](/docs/getting-started/)** — install the server, install the

## The two components

| Component | Repo | What it is |
|---|---|---|
| **Screensemble Player** | [Screensemble-Addon](https://github.com/Screensemble/Screensemble-Addon) | A Kodi addon that turns any Kodi-capable device into a managed signage display. |
| **Screensemble Server** | [Screensemble-Server](https://github.com/Screensemble/Screensemble-Server) | A small Node service + dashboard that coordinates, uploads to, and manages the whole fleet. |

You can run a display **without the server** (local mode), a display **with
the server** (managed mode), or many displays conducted together (controlled
mode, in development).
