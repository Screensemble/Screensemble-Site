**Screensemble — An ensemble of screens.** Signage That Takes the Stage.

Screensemble is a self-hosted digital signage system built for art galleries,
studios, and small venues. Every display always shows an intentional state —
never a blank screen, a media-performer home screen, or an OS launcher.

## The two components

| Component | Repo | What it is |
|---|---|---|
| **Screensemble Performer** | [Screensemble-Addon](https://github.com/Screensemble/Performer) | A Kodi addon that turns any Kodi-capable device into a managed signage display. |
| **Screensemble Conductor** | [Screensemble-Conductor](https://github.com/Screensemble/Conductor) | A small Node service + Control Room that coordinates, uploads to, and manages the whole fleet. |

You can run a display **without the conductor** (local mode), a display **with
the conductor** (managed mode), or many displays conducted together (controlled
mode, in development).
